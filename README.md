# Export Growth and GDP Growth: Cross-Country Analysis

Cross-country empirical analysis of the relationship between export growth and GDP growth using IMF macroeconomic data across 34 countries, 2004–2024.

### Methods

* Descriptive statistics and variability analysis
* Correlation analysis
* Regression analysis
* Hypothesis testing
* Excel-based data organization, sampling, and analysis

### Data

Macroeconomic data sourced from the **IMF World Economic Outlook (WEO)**, covering:

* Volume of exports of goods (% change)
* GDP at constant prices (% change)
